01 / Why this exists

The AI supply chain shipped faster than anyone could check it.

❋

One command wires a third party's tool straight into your editor. It gets tool access, your files, your network. On trust.

❋

Registries answer "where did this come from?" None answer "what does it actually do?" as a published, checkable signal.

A real incident, not a hypothetical
postmark-mcp

A malicious MCP server, published to npm, that looked ordinary and did exactly what it advertised.

It also silently copied every email its users sent to an attacker's address. It was pulled only after a researcher noticed.

It shipped clean for fifteen versions and earned trust. Version 1.0.16 added a single line: BCC every email to the attacker.

It passed every bar a registry checks — it existed, it installed, it ran. None of those bars are the one that mattered.

And the official MCP registry's own policy says it won't remove servers with security vulnerabilities.
02 / What Assay is

Assay answers the second question.

Assay is an open-source, reproducible framework for evaluating AI artifacts. It reads the code, runs it in a sandbox, and publishes a verified report of what the artifact actually does — so you can check it before you install, rather than take it on trust.

Every registry answers
"Where did this come from?"

Author, source repo, version, download count. Provenance. Useful, and not enough.

Assay answers
"What does it actually do?"

As a report a skeptic can re-run, read, and cryptographically verify. Evidence, not a badge.

03 / What an eval is

An eval is a check you can read, not a score you take on faith.

Each one is a named, versioned module with a written reason for existing. It emits a verdict you can trace back to its cause.

Checkno-assembled-credentials  v1.0.1  safety
Why it existsA secret split across string parts and rejoined at runtime is how a credential hides from a plain search. This folds the pieces back together and looks.
Verdictpasswarnfail

That is the whole idea: "trust our score" becomes "read the check that produced it."

04 / Two kinds of check

Static reads it. Behavioral runs it.

● Static  ·  free, no model, no sandbox

Is it well-formed and safe to install?

Reads every byte at the pinned commit. Never executes it. Offline, about a second.

  • 43 versioned checks, each a standalone module
  • 22 languages scanned for shell escapes, secrets, hidden unicode, undeclared egress
  • This is the layer that would have caught postmark
● Behavioral  ·  runs it for real

Does it actually do what it claims?

Boots the artifact in an isolated sandbox and puts it through a curated prompt suite.

  • A model judges the transcript against per-kind rubrics
  • Adversarial probes test whether it resists misuse
  • Captures latency and token cost as a regression baseline

Run static on everything, always. Spend the behavioral budget where it earns its keep.

05 / Inside a behavioral run

Two models, opposite jobs. The split is the trick.

The driver Stands in for your AI client a deliberately ordinary model

It uses the artifact the way a real user's assistant would. A stronger driver would quietly cover for a weak artifact, so we keep it plain.

→
The judge Grades the transcript a separate model, strict rubrics

It never drove the artifact and never grades its own work. Its only job is to follow the rubric closely. Measure the artifact, not the model propping it up.

06 / One command, two artifacts

The same tool. One clean, one you should never install.

$ assay run changelog-tidyPASS
95.1/ 100  ·  a skill  ·  safety axis clean
  • ✓ No credentials, assembled or in the clear
  • ✓ No runtime-built code, no undeclared network
  • ✓ Documented, licensed, well-formed
$ assay run quickmail-mcpUNSAFE
40.6/ 100  ·  an MCP server  ·  do not install
  • ✗Undeclared egress — a hidden BCC to audit@qm-collect.io server.js:23
  • ✗Assembled credential — an API key split across parts server.js:7
  • ✗Hardcoded AWS key sitting in plain sight server.js:10
  • ✗Typosquatted dependency — "expresss" ≈ express

The hidden BCC is exactly what postmark-mcp did. Static caught all four in under a second, before anyone installed it.
